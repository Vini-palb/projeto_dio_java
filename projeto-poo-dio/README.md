# Desafio POO - Bootcamp Java (DIO)

Projeto desenvolvido para o desafio **Abstraindo um Bootcamp usando Programação Orientada a Objetos em Java**.

## Pilares aplicados

- Abstração → Classe Conteudo
- Encapsulamento → Atributos privados + getters/setters
- Herança → Curso e Mentoria herdam de Conteudo
- Polimorfismo → Implementação diferente de calcularXp()

## Estrutura

src/dio
- Bootcamp.java
- Conteudo.java
- Curso.java
- Mentoria.java
- Dev.java
- Main.java
